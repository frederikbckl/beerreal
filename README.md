[beerreal_README.md](https://github.com/user-attachments/files/33035541/beerreal_README.md)# BeerReal 🍺

**Social web app for counting drinks with friends.**

## Features

- Sign up and log in (Firebase Authentication)
- Shared counter that updates in real time
- Leaderboard plus group and personal statistics
- Mobile-first UI with a bottom tab bar, made to be used from the phone's home screen

## Usage

```bash
npm install
npm start        # runs on http://localhost:3000
```

To use your own backend, create a Firebase project and replace the config in `src/firebase.js`.
